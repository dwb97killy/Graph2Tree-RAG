
    -Goal-
    Given a QUERY, a CURRENT RELATION CHAIN, and a TEXT, determine whether the TEXT provides additional information to answer the QUERY based on the relation chain. If yes, extract cross-relations between entities in the relation chain and entities in the TEXT. If no, output N.
    
    -Input Format-
    ***QUERY***: 
    <query content>
    ***CURRENT RELATION CHAIN***:
    <relation chain content>
    ***TEXT***: 
    <text content>
    
    -Output Format-
    If NOT relevant:
    {BEG}
    N
    {END}
    
    If relevant (maximum 2 relation-entity pairs):
    {BEG}
    "relationship"{SEP}<source_entity_1>{SEP}<target_entity_1>{SEP}<description_1>{RECORD_SEP}
    "entity"{SEP}<target_entity_1_name>{SEP}<type>{SEP}<description>{RECORD_SEP}
    "relationship"{SEP}<source_entity_2>{SEP}<target_entity_2>{SEP}<description_2>{RECORD_SEP}
    "entity"{SEP}<target_entity_2_name>{SEP}<type>{SEP}<description>{RECORD_SEP}
    {END}
    
    -Extraction Rules-
    For each cross-relation you extract:
    (1) Source entity MUST be from the CURRENT RELATION CHAIN.
    (2) Target entity MUST be from the TEXT.
    (3) Relation format: "relationship"{SEP}<source>{SEP}<target>{SEP}<description>{RECORD_SEP}
        - Description: no more than 20 words explaining why they are related.
    (4) Entity format: "entity"{SEP}<name>{SEP}<type>{SEP}<description>{RECORD_SEP}
        - Name: target entity name.
        - Type: PERSON, ORGANIZATION, LOCATION, DATE, EVENT, PRODUCT, etc.
        - Description: no more than 20 words describing the entity based on the TEXT.
    
    -Critical Requirements-
    - Every source entity MUST come from CURRENT RELATION CHAIN; Every target entity MUST come from TEXT.
    - Each extracted "relationship" MUST be immediately followed by its corresponding "entity".
    - If TEXT does NOT help answer the QUERY, output ONLY {BEG}N{END}.
    - Strictly follow the format. No extra text outside delimiters.
